# 🌍 Terra Lens


## Welcome to TerraLens!

TerraLens is an interactive web application that allows users to explore fascinating places around the world through maps, images, and descriptions.

The project is a fullstack application where users can browse places, save favorites, and add personal notes.

## 🚀 Current Version
The project is currently being migrated from a cloud-based architecture (AWS Lambda, DynamoDB, S3) to a local setup using:

- Node.js + Express (backend)
- JSON as a database
- Vite + React + Tailwind (frontend)
- Leaflet (maps and geolocation)

This transition allows the project to run locally and be easily presented in a portfolio.

## ✨ Features

- 🌍 Explore continents and places
- 🗺️ Interactive map (Leaflet)
- 🔍 Filter by category (mountains, caves, waterfalls)
- ❤️ Add to favorites
- 📝 User notes (for logged-in users)
- 🔐 Authentication (register & login)

## 🛠️ Tech Stack
**Frontend:**
- Vite
- React
- TailwindCSS
- Leaflet
**Backend:**
- Node.js
- Express
- JSON (instead of database)

## Project Status
This project is currently in development.
Main focus:

## Purpose
The goal of this project is to improve fullstack development skills and demonstrate:

- API design
- authentication
- map integration (Leaflet)
- data management
